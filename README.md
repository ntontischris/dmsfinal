# DMS (Devre Media System) — νέα έκδοση

Ο επανασχεδιασμός του εσωτερικού συστήματος διαχείρισης της Devre Media.

Σε αυτή τη φάση γράφεται το **Blueprint**, δηλαδή το εγχειρίδιο λειτουργίας του νέου συστήματος (ρόλοι, δυνατότητες, διαδικασίες, domain model, αρχιτεκτονική, στήσιμο). Κώδικας δεν γράφεται ακόμα.

Ο χάρτης της δουλειάς: [Wayfinder: Επανασχεδιασμός DMS](https://github.com/ntontischris/dmsfinal/issues/1)
